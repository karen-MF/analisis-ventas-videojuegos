# analisis-ventas-videojuegos

Proyecto de análisis exploratorio de datos enfocado en la industria de videojuegos. Se utilizó un dataset histórico de ventas globales para identificar tendencias por plataforma, género, región y relación entre reseñas y ventas.
## 🎯 Objetivos
- Limpiar y preparar datos.
- Analizar ventas por plataforma y género.
- Comparar preferencias regionales.
- Evaluar correlación entre puntuaciones y ventas.
- Probar hipótesis estadísticas.

## 🛠️ Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## 📊 Principales análisis
- Juegos lanzados por año.
- Ventas totales por plataforma.
- Distribución de ventas.
- Impacto de critic_score y user_score.
- Preferencias en Norteamérica, Europa y Japón.
- Pruebas estadísticas entre plataformas y géneros
